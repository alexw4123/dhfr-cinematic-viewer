# Human DHFR nucleopeptide research viewer

A separate, buildless research website for the Smith-Carpenter Lab project **Design and Evaluation of Nucleopeptide Candidates Targeting Human Dihydrofolate Reductase**. This folder does not modify the original heme viewer or the earlier cinematic experiments.

Open through a local HTTP server or static hosting. `index.html` loads local NGL 2.4.0 and `app.js`; no build, package installation, accounts, API keys, or network molecular service is required. The project report and external references retain their own access permissions.

## Molecular files

The two complexes are unchanged copies from the existing project assets. Each contains 3,153 atoms and 3,195 bonds copied from its matched PSF topology. The display PDB adds CONECT records; the original PDB atom records and coordinates are unchanged. NGL loads them with `inferBonds: 'none'`.

- Protein: zero-based atom indices 0–3012, 3,013 atoms, PROA / chain A.
- Modeled reduced NADPH: 3013–3086, 74 atoms, COFA / chain C.
- GS or isog candidate: 3087–3152, 66 atoms, LIGA / chain L.

`assets/dhfr-display-provenance.json` records original and derivative hashes and connectivity checks. Original PDBs, display PDBs, the local NGL library, and its license are included. No coordinates or topology were generated by this website.

Atomic view is the default and includes the hydrogens present in the source. Optional secondary structure is NGL's assignment from the protein coordinates. Candidate and NADPH remain atomic. The nearby pocket display selects complete protein residues with a heavy atom within 6 Å of a candidate heavy atom, plus NADPH and the candidate. It is not a binding, hydrogen-bond, or energy calculation.

The five-model preparation record includes free candidates and a DHFR–NADPH control, but only the two complex files are available interactively here. Component figures use selections of those actual complex coordinates and do not stand in for separately relaxed free/control calculations.

## Interaction and access

Six topics advance only when clicked. Selection emphasizes a component while retaining the whole model and camera position. Isolation and pocket zoom require explicit controls. Model switching preserves the camera. Drag rotates; wheel or pinch zooms. With the viewport focused, arrow keys rotate, + / − zoom, and Home resets. Buttons provide the same actions. A stationary single-finger tap picks source atoms; rotating or pinching does not select one.

The save-PNG control exports the live source-coordinate molecular view. It does not add a simulated assay plot or change coordinates.

## Evidence limits

These are static, unsolvated, unrelaxed 4M6K-derived preparation models. The candidate poses have unresolved overlaps. No current production DHFR trajectory, binding or inhibition measurement, cellular activity, selectivity, or safety result is represented. Methotrexate supplies established target context, not efficacy evidence for these candidates. Older archived 1U72 technical pilots are separate.

## Verification hooks

The visible model container `#molecular-viewport` exposes actual model-ready status, atom/bond counts, model key, component selection, selected atom count, representation, isolation, last picked source atom index, pocket counts, and the current camera orientation as DOM data attributes. The controls expose `aria-pressed`; captions and source-model metadata remain readable without inspecting developer tools.

Expected counts: 3,153 atoms and 3,195 explicit bonds for GS and isog, with no candidate–protein covalent bonds. Source and connectivity provenance can be verified independently with NGL's PDB parser and the source atom/CONECT records. Camera and selection actions must leave those source coordinates unchanged.

## Interactive application illustration

Delivery, cell entry, the DHFR target, and cancer relevance. IM injection is an educational route example; GS/isog have no established administration route or therapeutic effect. The application panel uses short, user-triggered 3D scenes with captions; it does not portray measured pharmacokinetics, chemical reaction dynamics, or treatment outcomes. The atomic NGL explorer and original molecular assets are preserved.
